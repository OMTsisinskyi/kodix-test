## Початок роботи

1. Створіть `.env` файл у кореневій директорії проекту та додайте наступне:

BACKEND_URL = "http://localhost:8000"
SESSION_SECRET_KEY = "{your-secret-key}"

Замість `{your-secret-key}` вкажіть ваш секретний ключ.

2. Виконайте команду для встановлення необхідних залежностей:

```bash
npm install

```

3. Запуск серверу

```bash
npm run dev
```

6. Тепер ви можете зайти на http://localhost:8000, щоб перевірити роботу бекенду.
